A production multi-agent framework: self-improving agents that research, plan, code, and execute tasks, deployable in a few lines with built-in memory, RAG, and support for 100+ LLM providers. Agents are wired together into workflows and can hand tasks to each other.

- primary substrate for `swarmgrid` topology experiments
- fleet memory behavior studied under long multi-agent runs
- task handoff patterns feed the lab's task-market research
